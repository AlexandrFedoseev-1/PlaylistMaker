# PlaylistMaker

The application for searching and playing music tracks with the ability to create playlists, add tracks to favorites, and store search history.

# Stack
- Android Studio
- Clean Arcitecture
- MVVM
- Single Activity
- Android Navigation
- Room
- Retrofit2
- StateFlow
